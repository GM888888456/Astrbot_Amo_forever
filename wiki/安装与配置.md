# 安装与配置

## 环境

- AstrBot 4.5.7 以上（推荐 4.29.x）
- 平台：QQ（aiocqhttp / NapCat）、飞书、钉钉、Telegram

## 安装

AstrBot 面板 → 插件 → 安装 → 填仓库地址：

```
https://github.com/GM888888456/Astrbot_Amo_forever
https://github.com/GM888888456/Astrbot_Amo_data
https://github.com/GM888888456/Astrbot_Amo_Speechsound
https://github.com/GM888888456/Astrbot_Amo_Image
https://github.com/GM888888456/Astrbot_Amo_Medical
https://github.com/GM888888456/Astrbot_Amo_Finance
```

装完重启 AstrBot。

## 最小可用配置

**只有终端是必须配的**，其余装上即用。

### 终端

| 项 | 说明 |
|---|---|
| 人格 / 称呼 | 她叫什么、怎么说话 |
| 模型 | 填聊天模型 |
| 心流阈值 | 默认 0.55，越高越少插话 |

### 记忆

装上就行，不用配。数据落在 `data/plugin_data/Astr_Amo_data/`。

### 语音

1. 去 [breezeblue.ai](https://breezeblue.ai) 注册，创建 API Key（形如 `brz_...`）；
2. 面板 → 配置 → 填 key → 保存；
3. 切到「音色」页 → 点「拉取音色」→ 按场景分配。

免费额度每天约 2000 汉字，个人用够。

### 相片

填一个 OpenAI 兼容的生图后端（`api_base` + `api_key` + `model`），面板里点「拉取」选模型。

### 医疗 / 金融

装上就有默认值。建议先做两件事：

1. 金融里确认城市和月薪（默认新一线 25k）；
2. 面板 → 资产：确认有没有房、有没有车。

## 关于城市

金融的房租和消费水平跟着**天气插件里配的城市**走。没有天气插件时按二线算。
