# 连接状态

每个挂载插件（记忆 / 语音 / 相片 / 医疗 / 金融）的面板最上面都有一行：

```
● 终端 v7.6.1 ｜ ● 记忆库 v2.8.0 ｜ bot_id 秦晓沫 ｜ 心跳 0 秒前
```

绿点＝连上了，红点＝没连上。鼠标停在那一行上会显示具体原因。

## 为什么放在各自插件里

不是让终端告诉大家「都连上了」，而是**每个插件自己报自己连没连上**。

终端挂了的时候，挂载插件的面板照样要能打开、照样要说清楚是谁没连上——
如果连接状态由终端统一提供，终端一挂，所有面板只会一起变成空白，看不出问题在哪。

## 接口

每个挂载插件都有 `GET /api/plug/<插件名>/health`：

```json
{
  "terminal_connected": true,
  "terminal_name": "Astrbot_Amo_forever",
  "terminal_version": "7.6.1",
  "data_connected": true,
  "data_name": "Astr_Amo_data",
  "data_version": "2.8.0",
  "bot_id": "秦晓沫",
  "last_heartbeat": 0,
  "error": ""
}
```

- `last_heartbeat`：距离上次连通多少秒。`0`＝现在就连着，`-1`＝从启动到现在没连上过。
- `error`：为空就是没问题；不为空是一句人话，直接显示给人看。

`/status` 里也带一份同样的 `link` 字段，面板不用多请求一次。

## 对不上的时候先看这里

| 现象 | 多半是 |
|---|---|
| 红点「终端未连接」 | 终端插件没装、没启用，或者正在重启 |
| 绿点终端、红点「记忆库未连接」 | 记忆插件没装/没启用，画像和记忆都读写不了 |
| 两个都绿但聊天不记事 | bot_id 和终端不一致（看那一行显示的 bot_id 是不是同一个人） |
| 心跳显示「从未连上过」 | 插件启动时终端还没加载，重启一次就好 |

## 谁记什么（避免重复）

- 每天发了几张图：**只记在相片插件**，终端不再自己数一遍；
- 服装库：只有一份 `wardrobe.json`（在终端的数据目录），相片插件的「服装」页只是代理；
- 人物参考图：只有一份（终端插件目录下的 `templates/`），相片插件不另存；
- 钱的明细：只有金融插件有账本，终端只转发和审批，不存余额。
