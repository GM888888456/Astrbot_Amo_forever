# 我想永远陪着你 · 使用手册

一套给 AstrBot 用的陪伴插件组。六块各管一件事，装多少都行，缺了会自动降级。

| 插件 | 仓库 | 管什么 |
|---|---|---|
| 我想永远陪着你-终端 | Astrbot_Amo_forever | 人格、聊天、心流、日程——她的本体 |
| 我想永远陪着你-记忆 | Astrbot_Amo_data | 记忆、画像、关系网、生命周期 |
| 我想永远陪着你-语音 | Astrbot_Amo_Speechsound | 出声 |
| 我想永远陪着你-相片 | Astrbot_Amo_Image | 出图 |
| 我想永远陪着你-医疗 | Astrbot_Amo_Medical | 生病、治疗、医保 |
| 我想永远陪着你-金融 | Astrbot_Amo_Finance | 账本、资产、收支、个税 |

## 五分钟装好

1. 在 AstrBot 插件页用仓库地址安装，六个仓库都可以装；
2. 重启 AstrBot；
3. 先配「终端」：填人设和模型；
4. 再配「记忆」：不用配，装上就行；
5. 最后按需装语音/相片/医疗/金融。

**只装终端也能用**，只是她不会出声、不会发照片、不会生病、不会花钱。

## 它们怎么连在一起

```
      你 ──聊天──▶ 终端（人格 + 心流判定）
                    │
      ┌─────────────┼──────────────┬────────────┐
      ▼             ▼              ▼            ▼
    记忆          语音           相片         医疗
  （记住事）    （说出来）      （拍给你）   （生病时）
                                               │ 要钱
                                               ▼
                                            金融（扣款）
```

关键：**医疗要花钱时，必须先问终端**，终端再让金融扣款。所以每一笔账她都知道。
