# 金融系统

她的钱包。钱从哪来、花到哪去、够不够花。

## 她有多少钱

**薪资按这个顺序取：面板里手动填的 → 人格里写的 → 所在城市的平均。**

人格里没写薪资是常态（很多人格只写性格），这时候不凭空编一个数字，按城市平均发：

| 城市档位 | 税前月薪 | 到手（扣完五险一金和个税） |
|---|---|---|
| 一线 | 13,000 | ≈ 10,600 |
| 新一线 | 10,000 | ≈ 8,400 |
| 二线 | 7,800 | ≈ 6,770 |
| 三线 | 6,000 | ≈ 5,390 |

人格里写「月薪 8000」「工资 1.2 万」「年薪 24 万」都会被读到（年薪 ÷12）。

每月 **10 号**发工资（面板可改 `pay_day`），发的是**扣完五险一金和个税的到手**：

| 项 | 金额（以 25,000 为例） |
|---|---|
| 税前月薪 | 25,000 |
| 五险一金（个人 22.5%） | -5,625 |
| 个税 | -1,465 |
| **到手** | **17,910** |

首月会多一笔 10% 的签约奖金。同一个自然月只发一次，重启不会重复发。

每月固定支出（租房、没车）：

| 项 | 金额 |
|---|---|
| 房租 | 3,200 |
| 物业 | 300 |
| 水电 / 燃气 / 网费 / 话费 | 390 |
| **合计** | **3,890** |

加上吃饭交通，一个月大概花 9,000～10,000，能存下 8,000 左右。

## 房子和车

**房子是送的，住还是要花钱。**

| 资产状态 | 房租/车贷 | 仍然要交 |
|---|---|---|
| 租房 | 扣房租 | 物业、水电、燃气 |
| 有房 | **不扣房租** | 物业、水电、燃气照扣 |
| 没车 | 不扣 | — |
| 有车 | **不扣车贷** | 车险、油费、停车 |

在面板「资产」里勾上「名下有房 / 名下有车」，下个月起自动生效。

## 钱怎么花出去的

所有支出都走同一个入口：

```
医疗/房租/购物 → 终端 charge(金额, 原因) → 金融扣款
                                        → 数据记账
                                        → 扣不到就返回「差多少」
```

**没有模块能绕过终端直接扣钱。** 这样每笔账她都知道。

## 没钱会怎样

- 余额撑不住一个月的固定支出 → 焦虑缓慢上涨；
- 生病付不起 → 病继续拖着，可能加重；
- 她会开口跟你商量（见 [医疗系统](医疗系统)）。

## 指令

| 指令 | 说明 |
|---|---|
| `/money`（`/钱包` `/余额`） | 看她还有多少钱 |
| `/bill`（`/账单`） | 最近 8 笔流水 |
| `/setmoney 5000` | 直接改余额（管理员） |

## 面板

- **钱包**：余额、储蓄、本月收支、焦虑程度；
- **每月固定**：这个月要交哪些钱；
- **资产**：勾有房有车、填月供；
- **最近流水**：正常交易只在这里显示，不打日志。

## 物价

内置一张价格表（奶茶 18、外卖 35、挂号 50、阑尾炎手术 12000…）。可以在配置 `prices` 里覆盖单项。

**为什么不实时抓现实物价**：价格每天抖会让账目失真，抓取失败还要维护兜底。静态表 + 偶尔手动校准，稳定性更重要。
