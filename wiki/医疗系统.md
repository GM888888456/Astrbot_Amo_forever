# 医疗系统

她生病了，要不要治、治不治得起。

## 流程

```
她生病了
  → 医疗算出要花多少（含医保报销）
  → 上报终端
  → 终端让金融扣款
  → 扣到了？治好 : 不治，病情继续
```

**医疗自己不碰钱。** 它只负责「这病怎么治、多少钱」，钱交给终端统一调度。

## 病情分级

| 病 | 严重度 | 治疗费 | 不治会变成 |
|---|---|---|---|
| 过度疲劳 | 轻 | 0（休息） | — |
| 轻微不适 | 轻 | 30–80 | 感冒 |
| 感冒 | 轻 | 150–300 | 发烧 |
| 发烧 | 中 | 300–600 | 肠胃炎 |
| 肠胃炎 | 中 | 800–1500 | 阑尾炎 |
| 阑尾炎 | 重 | 8000–15000 | — |
| 骨折 | 重 | 6000–20000 | — |

## 什么时候会生病

每天抽一次，基础概率 2%（约 50 天一次）：

| 条件 | 增加 |
|---|---|
| 下雨 / 暴雨 / 下雪 | +3% |
| 气温低于 8℃ | +2% |
| 经期 | +2% |
| 疲惫 > 65 | +2% |

## 医保

| 类型 | 起付线 | 报销比例 |
|---|---|---|
| 门诊 | 300 | 70% |
| 住院 | 1500 | 85% |
| 大病（超 2 万部分） | — | 再报 60% |

年度上限 30 万。

**举例**：阑尾炎 12,000 元
- 医保报 8,925
- 自付 **3,075**

所以有医保的人不会因为一场手术破产——这就是真实感。

## 她会硬扛

小病有概率先不去医院，余额越紧张越可能扛：

| 余额情况 | 去医院的概率 |
|---|---|
| 余额 ≥ 自付的 3 倍 | 75% |
| 余额 ≥ 自付 | 45% |
| 余额 < 自付 | 一定不去 |

拖着不治，病会升级。轻微不适 → 感冒 → 发烧 → 肠胃炎 → 阑尾炎。

## 没钱了会找你

病重又付不起时，她会开口跟你商量——「有点难受，钱不太够咋办」。
把选择留给你：给钱就去治，不给就继续扛。
