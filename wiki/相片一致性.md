# 相片一致性

同一个人的照片，不该一张一个样。

## 三个锚点

### 1. 脸

第一次成功出图后，把当时的外观描述冻结进 `face_lock.json`。之后即使用户改配置，已经定下的脸也不会跟着漂。

提示词里点名具体特征：脸型、五官比例、眼睛形状与眼距、鼻子、嘴唇、眉形、发际线、肤色。

### 2. 环境

地点 → 固定环境描述，一共九类：

| 地点 | 环境 |
|---|---|
| 公司 / 写字楼 | 玻璃幕墙、浅灰地毯、白色工位隔断、深蓝色企业招牌 |
| 家 / 宿舍 | 浅色墙面、木地板、米色窗帘、靠墙木桌、暖光台灯 |
| 咖啡店 | 深色木桌、皮质卡座、玻璃吊灯、黑板菜单 |
| 地铁 | 灰瓷砖、白色灯管、蓝底站名牌 |
| 街道 | 浅色地砖、行道树、沿街店铺 |
| 学校 | 长条木桌、白色立柱、浅绿公告板 |
| 餐厅 | 暖黄吊灯、木质方桌、菜单板 |
| 商场 | 抛光地砖、玻璃橱窗、条形灯带 |
| 户外 | 草地步道、连续树木、水面 |

同一地点永远命中同一条。地点读不到时沿用上次记住的（`scene_lock.json`）。

### 3. 姿势

**自拍**：一只手在画面下方举着手机、手臂自然伸出，**手机本身不入镜**（前置摄像头看不到手机），另一只手自然垂放。禁止双臂环抱、抱臂、双手交叉抱胸。

**他拍**：拍摄者在镜头后方，画面里不出现拍摄者和手机。

## 批量发送

一条指令里用换行、分号或竖线写多个提示词：

```
拍一张在公司的
拍一张在家的
```

会一次画完，**合成一条消息发出去**，不刷屏。坏掉一张不影响其他几张。

上限默认 4 张，面板可调。
